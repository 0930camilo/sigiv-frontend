Sobre SIGIV

SIGIV (Sistema de Gestión de Inventario y Ventas) nació como una solución para el desafío que enfrentan las pymes: la necesidad de centralizar el control de productos, inventario, proveedores, ventas y facturación en una única plataforma accesible.

Desarrollo y Tecnología

Desarrollado por Camilo Pérez Velásquez, Profesional en Sistemas, este proyecto utiliza tecnologías robustas para garantizar un sistema estable y escalable: Spring Boot para un backend potente, Angular para una interfaz de usuario moderna y MySQL/TiDB para la persistencia de datos.

¿Para Quién Está Diseñado SIGIV?

SIGIV está orientado principalmente a pequeñas y medianas empresas que necesitan una herramienta centralizada para la gestión de productos, inventario, proveedores y ventas en una plataforma web accesible y fácil de usar.

Ideal para:

Tiendas Distribuidores Comercios Minoristas Negocios con Inventario
